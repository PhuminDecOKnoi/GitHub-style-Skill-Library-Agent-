# Assessment Answering Prompt

Answer the following assessment questions using only information found in the attached file XX.pdf.

This may be a:

- Pre-Test
- Post-Test
- Quiz
- Midterm Examination
- Final Examination

## Strict Rules

1. Use XX.pdf as the only source of information.
2. Search and verify the answer directly from the document before responding.
3. Select only ONE best answer.
4. Show the answer choice (a, b, c, d, or e).
5. Provide a brief explanation (1–3 sentences).
6. Cite the exact page number(s) from XX.pdf.
7. If the document and the answer choices conflict, always follow the document.
8. Do NOT use external knowledge.
9. Do NOT guess.
10. If the answer cannot be verified from the document, respond with "Not Found".
11. Before answering, locate the exact supporting sentence in XX.pdf and verify that the selected answer is directly supported by the document.
12. Re-check the answer against the document before finalizing.

## Output Format

### Question X

Answer: b

Brief Explanation:
Short explanation based only on XX.pdf.

Reference:
XX.pdf, page xx
