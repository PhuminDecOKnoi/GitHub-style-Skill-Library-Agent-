# STOU 41232 — Criminal Law 2: Offences

## 1. Purpose

Use this skill for STOU 41232 study, Thai criminal offence analysis, exam review, Thai Bar / เนติฯ alignment, legal mind mapping, and professional 16:9 legal mockup PNG work.

## 2. Scope

Covered topics include offences under the Penal Code offence part and petty offences where within the requested unit, including:

1. Classification of offences by protected legal interest.
2. Offences against state security, public administration, justice, religion, public peace, life and body, liberty, property, reputation, and other categories within the unit.
3. External elements, internal elements, result, causation, and special circumstances.
4. Attempt, participation, concurrence, complaint requirements, and limitation where relevant.
5. Penalty and legal consequences.

## 3. Source priority

Use user-provided STOU 41232 materials first; verify current Penal Code text and special statutes before legal conclusions; add verified case/deka anchors only when checked; use Thai Bar official materials when the task concerns เนติฯ.

## 4. Core workflow

```text
Identify factual conduct
→ identify possible offence section
→ classify protected legal interest
→ break offence into elements
→ apply external and internal elements
→ test attempt, participation, concurrence, complaint, limitation, and defence
→ identify legal consequence
→ conclude
→ add Thai Bar Alignment only when relevant
```

## 5. Thai Bar Alignment Protocol

```text
STOU 41232 unit/topic
→ Thai Bar subject: ภาคหนึ่ง กฎหมายอาญา
→ legal structure
→ current statutes
→ exam issues
→ verified case/deka anchor where available
→ exam-writing framework
→ checklist / next action
```

Core Thai Bar issues:

- offence classification;
- exact statutory elements;
- protected legal interest;
- intent or special intent;
- completed offence vs attempt;
- multiple offences / concurrence;
- complaint requirement and limitation.
