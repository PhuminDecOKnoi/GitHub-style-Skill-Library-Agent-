# STOU 41216 — Criminal Law

## 1. Purpose

Use this skill for STOU 41216 study, Thai criminal-law issue analysis, exam review, Thai Bar / เนติฯ alignment, legal mind mapping, and professional 16:9 legal mockup PNG work.

## 2. Scope

Covered topics include:

1. General principles of criminal liability.
2. Elements of offence: act, result, causation, intent, negligence, and special elements.
3. Attempt, impossibility, preparation where relevant.
4. Principal, instigator, supporter, and participation.
5. Justification, excuse, mistake, necessity, self-defence, consent where relevant.
6. Specific offences and petty offences in the STOU scope.
7. Punishment, multiplicity, complaint requirements, and limitation.

## 3. Source priority

Use user-provided STOU materials first; verify the current Penal Code and special criminal statutes before giving operative conclusions; add verified Supreme Court anchors only when checked; use Thai Bar official materials when the task concerns เนติฯ.

## 4. Core workflow

```text
Identify alleged act and actor
→ identify possible offence / general principle
→ break offence into external and internal elements
→ check participation, attempt, defences, excuse, and limitation
→ apply facts to elements
→ identify penalty/remedy route where relevant
→ conclude
→ add Thai Bar Alignment only when relevant
```

## 5. Thai Bar Alignment Protocol

```text
STOU 41216 unit/topic
→ Thai Bar subject: ภาคหนึ่ง กฎหมายอาญา
→ legal structure
→ current statutes
→ exam issues
→ verified case/deka anchor where available
→ exam-writing framework
→ checklist / next action
```

Core Thai Bar issues:

- criminal elements;
- mens rea / intent / negligence;
- causation and result;
- attempt;
- principals and accomplices;
- defences and excuses;
- complaint requirements and limitation;
- penalty consequence.


## 10. Guardrails

- Do not infer guilt from allegations or internal disciplinary findings.
- Separate criminal elements from civil liability or labour consequences.
- Do not invent penalties, case numbers, or complaint periods.
- Do not create a standalone `/SKILL neti/bar *` workflow.
